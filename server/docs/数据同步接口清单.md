# 数据同步接口清单（Wildberries / Ozon）

> 本文档从「外部平台 API 接口」维度，梳理鲲鹏系统当前从 Wildberries、Ozon 同步的所有数据：
> 每个接口由**哪个调度任务**触发、经**哪个同步服务方法**处理、数据最终写入**哪张 ODS 表**，
> 以及接口的**请求地址**与**官方文档地址**。
>
> 链路：`调度任务(jobs) → 同步服务(services) → 平台客户端(clients) → ODS 表(models/ods)`
>
> 说明：
> - `同步机制`列给出调度频率与 `job_id`（生产环境由独立调度进程 `kunpeng.scheduler_main` 注册）。
> - `数据库表`列为 `__tablename__`，均属 ODS 贴源层。
> - 标注「已封装未调度」的接口：客户端已实现，但当前没有定时任务调用（手动/预留）。
> - 字段口径：平台返回 camelCase，落库统一转 snake_case。
