# Kunpeng 数据库表结构文档

> 本文档依据模型源码（`src/kunpeng/models/`）和 Alembic 迁移维护，覆盖全部数据表，供数据分析师和维护人员查阅。
> 如模型有变更，应同步新增迁移并更新本文档（见文末“如何更新”）。

**数据来源**：Wildberries、Ozon 电商平台 API
**表总数**：91 张（业务/系统表 3，Wildberries ODS 39，Wildberries DWD 9，Ozon ODS 34，Ozon DWD 6）

所有 ODS 表均继承公共时间戳字段：`create_time`（创建时间）、`update_time`（更新时间）；多数表带 `shop_id`（多租户店铺隔离）与 `row_data`（原始 API JSON，用于追溯）。

DWD 表是在 ODS 原始数据基础上清洗、关联和统一业务口径后的明细表。DWD 表以稳定的业务主键保证幂等，不保留 `row_data`，需要追溯原始响应时应回查对应的 ODS 表。

## 业务 / 系统表

### `shops`

**表说明**：店铺表

**主键**：`id`

**唯一约束**：`uq_shop_user_platform_platformid` (user_id, platform, platform_shop_id)

**索引**：`idx_shop_user_id` (user_id)；`ix_shops_id` (id)；`ix_shops_platform_shop_id` (platform_shop_id)；`ix_shops_platform` (platform)；`ix_shops_user_id` (user_id)

| 字段名 | 类型 | 允许NULL | 说明 |
|--------|------|----------|------|
| id | INTEGER | ❌ | 主键ID |
| name | VARCHAR(255) | ❌ | 店铺名称 |
| platform | VARCHAR(50) | ❌ | 平台(wildberries, ozon) |
| platform_shop_id | VARCHAR(255) | ✅ | 平台店铺ID |
| api_key | TEXT | ✅ | API密钥(加密存储) |
| performance_client_id | VARCHAR(255) | ✅ | Ozon广告API Client-Id |
| performance_client_secret | TEXT | ✅ | Ozon广告API Client-Secret(加密存储) |
| user_id | INTEGER | ❌ | 用户ID |
| create_time | DATETIME | ❌ | 创建时间 |
| update_time | DATETIME | ✅ | 更新时间 |

### `user_shop_access`

**表说明**：为普通用户授予已有店铺的只读访问权限；店铺所有权仍由 `shops.user_id` 表示。

**主键**：`id`；**唯一约束**：`uq_user_shop_access_user_shop` (`user_id`, `shop_id`)

**外键**：`user_id` → `users.id`；`shop_id` → `shops.id`，均使用级联删除。

**索引**：`idx_user_shop_access_user_shop` (`user_id`, `shop_id`) 以及两个外键字段索引。

| 字段名 | 类型 | 允许NULL | 说明 |
|---|---|---|---|
| id | INTEGER | ❌ | 自增主键 |
| user_id | INTEGER | ❌ | 被授权用户ID |
| shop_id | INTEGER | ❌ | 授权店铺ID |
| create_time | DATETIME | ❌ | 创建时间 |
| update_time | DATETIME | ✅ | 更新时间 |
