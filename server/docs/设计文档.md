# 跨境电商数据采集和分析系统 - 设计文档

## 1. 项目概述

### 1.1 项目目标

为跨境电商卖家提供一站式数据分析与运营决策支持平台，核心功能包括：

- 店铺诊断与优化
- 竞品洞察与市场研究
- 决策支持与效率提升

### 1.2 支持平台

- 初期：Wildberries
- 预留：Ozon、AliExpress、Amazon等

---

### 2.2 技术选型

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + TypeScript | 渐进式框架，类型安全 |
| 前端构建 | Vite | 快速开发构建 |
| UI组件 | Element Plus | 企业级UI组件库 |
| 状态管理 | Pinia | Vue3官方推荐状态管理 |
| 后端 | FastAPI | 高性能异步Web框架 |
| ORM | SQLAlchemy 2.0 | 成熟的ORM，支持异步 |
| 数据库 | SQLite/MySQL | 开发用SQLite，生产用MySQL |
| 认证 | JWT | 无状态认证 |
| 任务调度 | APScheduler | 功能强大的调度库 |
| HTTP客户端 | httpx + tenacity | 异步HTTP + 重试机制 |
| 限流 | 令牌桶算法 | 平滑的限流策略 |

## 6. 核心模块设计

### 6.1 平台API客户端

**职责**：封装电商平台API调用，提供统一接口

**特性**：
- 令牌桶限流
- 自动重试（指数退避）
- 统一错误处理
- 支持多平台扩展

**基类设计**：
```python
class BasePlatformClient:
    def __init__(self, api_key, base_url, rate_limit_calls=100, rate_limit_period=60):
        self.api_key = api_key
        self.base_url = base_url
        self.rate_limiter = RateLimiter(rate_limit_calls, rate_limit_period)

    @retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=2, max=10))
    async def _request(self, method, endpoint, **kwargs):
        await self.rate_limiter.acquire()
        # 发送请求...
```

### 6.2 任务调度器

**职责**：管理定时任务执行

**内置任务**：
- 订单同步：每30分钟
- 销售数据同步：每小时
- 财务报表同步：每天
- 广告数据同步：每小时

**调度方式**：
- 使用APScheduler的CronTrigger
- 支持动态添加/删除任务
- 任务持久化（可选）

### 6.3 限流算法

**实现**：令牌桶算法

**参数**：
- Wildberries：默认100次/分钟
- 可配置不同平台的限流策略

## 7. 安全设计

### 7.1 认证授权
- JWT无状态认证
- Token有效期：30天
- 基于角色的访问控制（RBAC）

### 7.2 数据安全
- API密钥加密存储
- 密码使用bcrypt哈希
- HTTPS传输加密
- 敏感数据脱敏

### 7.3 API安全
- 请求频率限制
- SQL注入防护（SQLAlchemy ORM）
- XSS防护（前端 + 后端）
